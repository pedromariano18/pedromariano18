# Pedro Mariano

MSc student in Network and Computer Systems Engineering at FCUP (Universidade do Porto).
Bachelor's in Computer Engineering from the University of Aveiro.

Currently focused on network protocols, security, and distributed systems.
Previously developed a real-time sensor fusion system at Instituto de Telecomunicações Aveiro, integrating radar, weather, and camera data for A25 highway traffic management.

---

### Areas of interest

- Network protocols & performance (HTTP/2, HTTP/3, QUIC, OSPF)
- Network security (PKI, honeypots, intrusion detection)
- Data science & ML applied to networks
- Systems programming and low-level networking
